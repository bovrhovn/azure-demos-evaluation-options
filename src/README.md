# Source Code

This folder contains all demo source code for the AI evaluation options project.

| Folder | Description |
|---|---|
| [`agent-framework/`](agent-framework/README.md) | Evaluation demos using Microsoft Agent Framework (Semantic Kernel Agents) |
| [`foundry-sdk/`](foundry-sdk/README.md) | Evaluation demos using Azure AI Foundry SDK |

## Getting Started

Before running any demos, ensure you have completed the project setup:

```bash
bash ../scripts/setup.sh
```

See the [project README](../README.md) for full prerequisites and setup instructions.
